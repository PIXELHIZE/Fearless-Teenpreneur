# teum

목표만 알려 주면 **커리큘럼 설계 · 일정 배치 · 자료 생성 · 학습 분석 · 계획 수정**까지
AI Agent 가 이어서 해 주는 학습 서비스. SDG 4(양질의 교육)의 학습 지원 격차를 줄이는 것이 목표입니다.

디자인은 `../design_system` 의 teum Interface System 을 토대로, 학습 앱답게 밝고 경쾌하게 다시 잡았습니다.
코발트 블루가 대표색이고 초록(정답·성장)·노랑(에너지)·코랄(오답)·퍼플(AI 에이전트)이 보조색입니다.
버튼은 아래로 눌리는 3D 버튼, 정답·오답은 아래에서 올라오는 색 배너, 결과는 컨페티와 카운트업으로 축하합니다.
모바일·태블릿에서 쓰는 것을 기준으로 폰 폭 한 열을 가운데에 세웁니다. (`styles/tokens.css`, `app/globals.css`)

## 실행

```bash
npm install
cp .env.local.example .env.local   # OPENROUTER_API_KEY 입력
npm run dev                        # http://localhost:3000
```

데이터는 외부 서비스 없이 **SQLite**(`data/teum.db`) 에 들어갑니다. 첫 실행 때 스키마가 자동으로 생깁니다.
모델은 OpenRouter 의 `google/gemini-3.8-flash`, 공급자는 `google-ai-studio` 로 고정했습니다.

## 화면

하단 탭은 **수업 · AI 노트 · 홈 · 내 정보** 네 개이고, 홈이 가운데에서 강조됩니다.

| 경로 | 내용 |
| --- | --- |
| `/signup`, `/login` | 이메일 가입·로그인 (scrypt 해시, httpOnly 세션 쿠키) |
| `/onboarding` | 이름 → 성별 → 나이 → 공부 가능 시간 → 목표 → 분석. 단계마다 GSAP 진입 모션 |
| `/home` | 가장 가까운 수업, 이번 주 캘린더, 기초 학습, 지난 피드백, 목표 진행도 |
| `/lessons` | 현재 시각 이후 수업 10개 (진행 중 포함). 시간이 되면 눌러 시작 |
| `/lesson/[id]` | 카드뉴스 → 퀴즈 → 시험지 → 결과. 중간에 나가도 이어서 |
| `/note`, `/note/[id]` | AI 노트. 수업 시험지·**맞춤 시험지**를 손으로 풀고 채점·피드백 받기, AI 펜으로 물어보기 |
| `/calendar` | 공부 가능 시간·개인 일정 설정, 수업 삭제 |
| `/me`, `/me/history` | 프로필(레벨·연속·시간), 목표와 커리큘럼, 커리큘럼 변경 기록, **피드백·수업 기록** |
| `/study/[kind]` | OX 퀴즈 · 카드 뒤집기 · 따라쓰기 (탭바 없는 집중 화면) |

오른쪽 아래에는 채널톡 같은 **AI Agent 대화**가 항상 떠 있습니다. 여기서 일정·목표·커리큘럼을 바꾸고, "지금 30분만 봐 줘" 라고 하면 즉시 과외가 열립니다.

## 게임 요소

- **XP · 레벨** — 퀴즈 정답 10, 기초학습 정답 5, 수업 완료 50, 시험지 점수×2, 즉시 과외 완료 30. 200XP 마다 레벨업. (`lib/server/xp.ts`)
- **오늘 목표 링** — 하루 20분. 수업에 실제로 머문 시간으로 찹니다.
- **주간 활동 그래프** — 최근 7일 공부 시간. 목표선을 넘긴 날은 초록.
- **연속 일수** — 수업에 참여한 날이 이어지면 불꽃이 올라갑니다.

## 즉시 과외

홈의 "지금 바로 과외" 또는 에이전트 대화에서 시작합니다. 15·30·45·60분 중 고르면
에이전트가 주제(적지 않으면 약점·다음 단원에서 고름)를 정하고, 그 길이에 맞는 카드·퀴즈·시험지를 만들어 바로 수업을 엽니다.
끝나는 시각이 지나면 예약 수업과 똑같이 **분석 → 커리큘럼 조정** 파이프라인을 탑니다. (`lib/server/agent/instant.ts`)

## 시험지 (모의고사 형식)

수업 시험지와 맞춤 시험지는 같은 스키마(`lib/server/agent/exam-schema.ts`)를 씁니다.
5지선다가 기본이고 보기는 정확히 5개, 쉬운 문항부터, 지문·조건은 `passage` 로 분리합니다.
노트에는 ①~⑤ 로 그려지고, 손으로 표시한 것을 AI 가 읽어 채점합니다.
채점 결과에는 점수뿐 아니라 **잘한 점·보충할 점·다음에 공부할 것**이 함께 나오고, 이 피드백은 `feedback_log` 에 쌓여
다음 자료 생성과 커리큘럼 조정이 참고합니다.

## 카드뉴스 시각 자료

카드마다 모델이 `visual` 하나를 고릅니다 — `formula`(핵심 식), `steps`(순서), `compare`(두 개념 비교), `bars`(수치 비교),
`table`(정리), `example`(예제·풀이). 클라이언트가 그립니다 (`components/app/slide-visual.tsx`). 글로만 된 카드가 연달아 나오지 않게 프롬프트에서 막습니다.

## Agent 가 도는 순서

수업이 **끝나는 시각**(노트를 나간 시점이 아니라)을 서버가 스스로 알아채고, 1분마다 도는 작업이 다음 순서를 지킵니다.
`lib/server/pipeline.ts` · `lib/server/scheduler.ts`

```
수업 종료 감지
  → 학습 분석 (정답·오답 내용, 실제 참여 시간, 진행률)
  → 커리큘럼 조정 (숙련도 갱신, 단원 추가·비중 변경)  ← 다음 날 수업부터 반영
  → 다음 공부 시간에 쓸 자료 생성                      ← 직전이 아니라 이 시점에
```

자료는 수업 길이에 맞춰 분량을 먼저 정하고(`planPortion`) 그 개수만 만듭니다.
30분 수업과 90분 수업의 카드·문항 수가 다릅니다.

## 바꿀 수 있는 시점 (`lib/server/policy.ts`)

- **오늘 수업**은 사용자도 에이전트도 지우거나 덮어쓸 수 없습니다.
- 에이전트가 바꾸는 스케줄·커리큘럼은 **다가오는 수업을 건드리지 않고** 그 다음 수업부터 반영됩니다.
- 수업 종료 후 자동 분석의 커리큘럼 조정은 **다음 날 수업부터** 반영됩니다.
- 수업은 **최소 30분**이며, 공부 가능 시간 안에서만 잡힙니다.
- 반복 수업을 지울 때는 "이 수업만 / 반복 전체"를 묻고, 전체는 한 번 더 확인합니다.

## AI 노트와 AI 펜

시험지는 문항을 **이미지로 그려** 캔버스에 잠근 채로 올립니다(`lib/note/exam-sheet.ts`).
DOM 이 아니라 이미지여야 AI 펜이 캡처할 때 문제 본문까지 함께 읽힙니다.

AI 펜(단축키 `A`)은 궁금한 곳에 동그라미를 치면 그 자리에 피그마 코멘트 같은 핀을 남깁니다.

- 캡처 범위는 `현재 화면 ∪ (올가미 + 여백)` — 올가미 **밖**의 지문·앞 단계 식도 문맥으로 함께 읽습니다.
- 올가미 영역만 브랜드 블루 형광 + `TARGET` 라벨로 덧칠해 보냅니다.
- 탭은 **의미 · 요약 · 개념정리 · 오류 지적 · 힌트 · 풀이** 순서이고, 풀이는 항상 마지막이며 한 번 가려집니다.
- 핀은 탭하면 열리고, 꾹 누르면(0.5초) 삭제 아이콘이 뜹니다.

제출하면 노트 전체를 한 장으로 캡처해 보내고, AI 가 **손글씨를 읽어** 채점 기준대로 채점합니다.

## 구조

```
app/
  (auth)/           가입·로그인
  onboarding/       단계별 온보딩
  (app)/            탭이 있는 화면 (홈·수업·노트·내 정보·캘린더)
  study/[kind]/     기초 학습 (전체 화면)
  lesson/[id]/      수업 진행 (전체 화면)
  note/[id]/        노트 편집 (전체 화면)
components/
  ui/               design_system 의 shadcn 공용 소스
  system/           브랜드·모션 래퍼, 로고, 온보딩
  app/              탭바, 에이전트 대화, 수업·캘린더·기초 학습 화면
  note/             AI 펜 오버레이·메모 카드·노트 편집
lib/
  server/db.ts      SQLite 스키마와 연결
  server/agent/     커리큘럼 · 스케줄 · 자료 · 분석 · 시험지 · 즉시 과외 · 기초 문항 · 대화
  server/xp.ts      XP · 레벨 · 활동 · 피드백 로그
  server/policy.ts  무엇을 언제부터 바꿀 수 있는지
  server/pipeline.ts 수업 종료 → 분석 → 조정 → 자료 준비
  note/             AI 펜 도구·캡처·시험지 렌더
  actions/          서버 액션
```

## 메모

- AI 키가 없어도 앱은 켜집니다. 커리큘럼·일정은 기본값으로 만들어지고, 자료 생성과 대화는 멈춥니다.
- tldraw 는 상용 사용 시 라이선스가 필요합니다 (캔버스 오른쪽 아래 워터마크).
- 아이콘은 `lucide-react` 단색 아이콘만 씁니다. 이모지는 쓰지 않습니다.
